# Loan Approval Classification

This project uses machine learning to predict loan approval outcomes based on applicant and loan characteristics. It also evaluates fairness across demographic groups to better understand potential biases in the model.

## Project Overview

The project includes:
- Data preprocessing and exploratory data analysis (EDA)
- Feature engineering
- Machine learning model training and evaluation
- Fairness analysis
- A Streamlit web application for interactive predictions

## Dataset

- **Source:** Kaggle – Loan Approval Classification Dataset
